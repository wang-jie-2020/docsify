## 🚪 启动与退出

| 命令         | 功能               |
| ------------ | ------------------ |
| `vim file`   | 打开文件           |
| `:w` / `:q`  | 保存 / 退出        |
| `:q!`        | 强制退出不保存     |
| `:wq` / `ZZ` | 保存并退出         |

## 🧭 模式与插入

| 按键  | 功能         |
| ----- | ------------ |
| `Esc` | 回到普通模式 |
| `i`   | 光标前插入   |
| `a`   | 光标后插入   |
| `o`   | 下方新行插入 |
| `O`   | 上方新行插入 |
| `v`   | 字符可视模式 |
| `V`   | 行可视模式   |

## 💾 光标移动

| 按键        | 功能            |
| ----------- | --------------- |
| `h j k l`   | 左 下 上 右     |
| `w` / `b`   | 下一个 / 上一个单词 |
| `0` / `$`   | 行首 / 行尾     |
| `gg` / `G`  | 文件首行 / 末行 |
| `[n]G`      | 跳到第 n 行     |
| `Ctrl+f/b`  | 下一页 / 上一页 |
| `Ctrl+d/u`  | 下翻 / 上翻半页 |

## ✏️ 编辑

| 按键        | 功能                    |
| ----------- | ----------------------- |
| `x`         | 删除字符                |
| `dd`        | 删除整行（`[n]dd` 删 n 行）|
| `dw` / `diw`| 删除到词尾 / 删除当前单词 |
| `yy`        | 复制整行                |
| `p` / `P`   | 粘贴到光标后 / 前       |
| `u`         | 撤销                    |
| `Ctrl+r`    | 重做                    |
| `.`         | 重复上次操作            |
| `ciw`       | 修改当前单词            |
| `>>` / `<<` | 缩进 / 反缩进           |
| `gg=G`      | 全文格式化缩进          |

## 🔍 搜索与替换

| 命令                       | 功能             |
| -------------------------- | ---------------- |
| `/word`                    | 向下搜索         |
| `n` / `N`                  | 下一个 / 上一个  |
| `*`                        | 搜索光标下单词   |
| `:noh`                     | 取消搜索高亮     |
| `:%s/old/new/g`            | 全文替换         |
| `:%s/old/new/gc`           | 全文替换并确认   |

## 🗂 窗口与文件

| 命令       | 功能         |
| ---------- | ------------ |
| `:e file`  | 打开另一个文件 |
| `:sp file` | 水平分屏     |
| `:vsp file`| 垂直分屏     |
| `Ctrl+w` + `h/j/k/l` | 切换窗口 |
| `:bd`      | 关闭当前缓冲区 |
