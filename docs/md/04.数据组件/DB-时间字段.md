## MySQL

- DATE：仅日期，范围为 1000-01-01 至 9999-12-31。
- TIME：表示时间或时间间隔，范围为 -838:59:59 至 838:59:59。可指定小数秒精度，最高 6 位。
- YEAR：年份类型，通常用于表示年份；推荐使用四位年份值。两位年份输入有特殊解释规则，不应当作固定的 YY 存储格式。
- **DATETIME**：日期和时间，不进行时区转换；范围为 1000-01-01 00:00:00 至 9999-12-31 23:59:59。可指定最高 6 位小数秒精度。
- **TIMESTAMP**：日期和时间，写入时按会话时区转换为 UTC 存储，读取时转换回会话时区。可指定最高 6 位小数秒精度；范围依 MySQL 版本而异，常见 64 位版本可到 2038-01-19 03:14:07 UTC。

## SQL Server

- DATE：仅日期，范围 0001-01-01 至 9999-12-31。
- TIME：仅时间，可指定 0 至 7 位小数秒精度。
- DATETIME：日期和时间，范围 1753-01-01 至 9999-12-31；精度约为 1/300 秒，实际舍入通常以 .000、.003、.007 秒递增。
- **DATETIME2**：日期和时间，范围 0001-01-01 至 9999-12-31；精度可指定为 0 至 7 位小数秒，最高约 100 纳秒。
- ~~SMALLDATETIME：日期和时间，范围 1900-01-01 至 2079-06-06，精确到分钟。~~
- **DATETIMEOFFSET**：日期和时间加 UTC 偏移量；保存偏移量，但不保存时区名称或完整时区规则。

## Oracle

- **DATE**：包含年、月、日、时、分、秒，不包含小数秒或时区。显示格式由会话设置等决定，DD-MON-YY 不是固定存储格式。
- **TIMESTAMP**：在 DATE 基础上支持小数秒，默认精度为 6 位，最高 9 位。
- **TIMESTAMP WITH TIME ZONE**：包含时区偏移量或时区区域信息。
- TIMESTAMP WITH LOCAL TIME ZONE入库时按数据库时区规范化存储，读取时转换为会话时区；不保留输入时的原始时区偏移。
- INTERVAL YEAR TO MONTH、INTERVAL DAY TO SECOND：表示时间间隔，不是日期时间点。

## PostgreSQL

- DATE：仅日期，支持很宽的日期范围，包括公元前日期；实际范围受 PostgreSQL 的日期实现限制。
- TIME WITHOUT TIME ZONE：仅时间，不包含日期和时区。
- TIME WITH TIME ZONE（timetz）：仅时间并带时区偏移；由于没有日期，通常不适合处理依赖夏令时规则的现实时间。
- **TIMESTAMP WITHOUT TIME ZONE(timestamp)**：日期和时间，不带时区语义。
- **TIMESTAMP WITH TIME ZONE（timestamptz）**：表示一个时间点，输入时按偏移转换，输出时按会话时区显示；不保留输入的原始偏移或时区名称。
- INTERVAL：表示时间间隔。
- daterange、tsrange、tstzrange：分别表示日期、无时区时间戳和带时区时间戳的范围，不是基础日期时间字段类型。
