2. 问题记录：Feign 配置的超时时间

（1）代码中 FeignClient 的 Configuration.Class 无效，但是 LogLevel 生效

（2）通过覆盖 nacos 中的 default 配置解决问题

```yml
feign:
  client:
    config:
      default:
        connectTimeout: 100000
        readTimeout: 600000
  compression:
    request:
      enabled: false    # 关闭请求压缩
    response:
      enabled: false    # 关闭响应压缩
```
