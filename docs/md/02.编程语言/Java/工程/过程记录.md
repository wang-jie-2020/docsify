## MVC

### 1. 端点路由

1. URL大小写绑定敏感

2. `@RequestParam` 通常理解是Query参数, 实际还包含以下的:

   (1) application/x-www-form-urlencoded 请求体

   (2) multipart/form-data 中的普通文本字段

   (3) multipart 中的文件参数

   避免同名参数(同名结果合并), 要强制绑定来源时`@RequestBody`、`@RequestPart("file")`

### 2. JSON

1. 通过`Jackson2ObjectMapperBuilderCustomizer`定制项目个性化, `MappingJackson2HttpMessageConverter`和`ObjectMapper`的重写会覆盖掉框架默认值
2. 日期、Number长度 的序列化补充
3. 枚举时默认使用name, 通常不太符合习惯, 通过`@JsonValue`可以修改

### 3. 容器上下文

*BeanDefinition -> BeanRegistry -> BeanFactory -> BeanInstance 的过程见相关章节, 实例Bean的过程:*

`ctor` -> `BeanPostProcessor(Before)` -> `@PostConstruct` -> `InitializingBean.afterPropertiesSet()` -> `BeanPostProcessor(After)`

### 4. 静态资源

1. `ClassUtils.getDefaultClassLoader()`  -> classpath, 类似的 `ResourceUtils`、`ClassPathResource`

2. classpath的以下路径可直接访问: `/static`、`/public`、`/resources`、`/META-INF/resources`

3. 其他物理路径的访问: `WebMvcConfigurer.addResourceHandlers()`

### 5. 全局异常

`@ControllerAdvice`

### 6. 文件服务

1. `MultipartFile`, 注意`spring.servlet.multipart.max-file-size` `spring.servlet.multipart.max-request-size`配置
2. 代理的转发头, 通常 `server.forward-headers-strategy: framework`

### 7. 上下文对象

*线程上下文: ThreadLocal、InheritableThreadLocal、TransmittableThreadLocal(类似AsyncLocal)*

​	`RequestContextHolder.getRequestAttributes()`

### 8. 线程池 / Async

1. `@EnableAsync`、`@Async`: aop约束条件
2. `TaskExecutor` 配置默认实现`ThreadPoolTaskExecutor`(注意名称Task)
3. 池大小、队列类型&长度、拒绝策略等等颇有戏剧
4. 短耗时的异步操作(例如`CompletableFuture`)、长期后台执行的任务是考虑范围, 周期性操作转移走合适

### 9. 过滤拦截

1. 过滤 的场景不多, 一个参数初始化问题, 一个委托过滤链问题
